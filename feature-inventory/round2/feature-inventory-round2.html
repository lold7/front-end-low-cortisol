    hash รหัสของ admin@bookstore.com ใน init.sql เป็นค่าหลอก และ /backoffice/register ต้องล็อกอินเป็น admin ก่อน → ไม่มีทางเข้าหลังบ้านนอกจากแก้ DB เอง ควรใส่ bcrypt hash จริงใน init.sql หรือทำสคริปต์ seed admin
  • ลิงก์รีเซ็ตรหัสยังโชว์บนหน้าเว็บ [A3]
    ใครกรอกอีเมลของคนอื่นก็เห็นลิงก์ได้ทันที ใช้ demo ได้ แต่ถ้าขึ้นจริงต้องส่งทางอีเมลอย่างเดียว
  • หน้า 403 และหมวดที่ถูกซ่อนยังเป็นข้อความล้วน [A7, B4]
    “Access Denied: Admins Only” และ “Category not found” ยังไม่ใช้หน้า 404/403 แบบใหม่
  • เนื้อหา /condition ไม่ใช่เงื่อนไข [B9]
    หน้าเป็นหน้าชวนล็อกอิน/สมัคร (title “Login-condition”)
  • จุดเล็ก ๆ ที่ยังเหมือนเดิม [F2, B2, B6, A5]
    pagination หลังบ้านมีลิงก์ page=0 · /products?page เกินจำนวนเป็นหน้าว่าง · อีเมล John ใน init.sql พิมพ์ผิด (john@bookstore.comcart_items) · รูปปกบางเล่มไม่ตรง · สร้าง admin เสร็จพาไปหน้า login ทั้งที่ล็อกอินอยู่
